# DriftGuard

Paste a public GitHub repo to find the drift AI coding leaves behind (copied code, competing libraries, unused dependencies, docs that no longer match the code), then ask questions about the code and get answers with file and line citations.

Source code, docs and measured accuracy: https://github.com/harishni-5/driftguard
