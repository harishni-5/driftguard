# DriftGuard

Finds the mess AI coding assistants leave behind: the same job done in different ways, docs that promise what the code doesn't do, and dependencies nobody uses.

- **[Sample report](sample-report.html)**: a real audit of [e2b-dev/fragments](https://github.com/e2b-dev/fragments). Click a finding to see the evidence, and click a file to jump to the exact line on GitHub.
- **[How it works](how-it-works.md)**: the pipeline, how each agent decides, and known limits.
- **[Decisions and results](DECISIONS.md)**: every measurement, and why each change was made.
- **[Source code](https://github.com/harishni-5/driftguard)**
